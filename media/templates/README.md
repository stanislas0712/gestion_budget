# Templates Vierges pour Formation

Ce dossier contient les templates vierges (modèles vides) que les opérateurs peuvent télécharger pour s'exercer.

## Fichiers à créer

Vous devez créer 3 fichiers de templates :

1. **template_budget.xlsx** - Template Excel
2. **template_budget.pdf** - Template PDF
3. **template_budget.docx** - Template Word

## Structure du template

Chaque template doit contenir la structure budgétaire complète :

### Section A - Formation
- **A.1 - Matières d'œuvre**
  - Intrants et/ou matières premières
  - Petites Fournitures Pédagogiques

- **A.2 - Coûts pédagogiques**
  - Frais pédagogiques
  - Honoraires
  - Rapportage
  - Prise en charge des apprenants

### Section B - Stage + Insertion
- Activités d'appui à l'insertion

### Colonnes du tableau

Pour chaque ligne budgétaire :
- **Désignation** : Description de l'article
- **Unité** : Unité de mesure
- **Quantité** : Nombre d'unités
- **Prix Unitaire (FCFA)** : Prix par unité
- **Coût Total (FCFA)** : Quantité × Prix Unitaire
- **Co-financement (FCFA)** : Montant co-financé
- **Budget Demandé (FCFA)** : Coût Total - Co-financement

### Synthèse finale

- **COUT TOTAL/BUDGET (A+B)**
- **COUT UNITAIRE TOTAL /APPRENANT (FCFA)**

## Comment créer les templates

### Excel (.xlsx)
1. Créez un fichier Excel avec la structure ci-dessus
2. Formatez les en-têtes en gras avec couleur de fond
3. Ajoutez des bordures aux cellules
4. Sauvegardez comme `template_budget.xlsx`

### PDF (.pdf)
1. Créez le template dans Excel ou Word
2. Exportez en PDF
3. Sauvegardez comme `template_budget.pdf`

### Word (.docx)
1. Créez un document Word avec un tableau
2. Reproduisez la structure budgétaire
3. Sauvegardez comme `template_budget.docx`

## Emplacement

Placez tous les fichiers dans ce dossier :
```
media/templates/
├── README.md (ce fichier)
├── template_budget.xlsx
├── template_budget.pdf
└── template_budget.docx
```

## Accès

Les opérateurs peuvent télécharger ces templates depuis le dashboard via le bouton **"Télécharger template"**.
